# 四層地牢 MUD 冒險（網頁版）

由 `game.c` 移植的瀏覽器版文字冒險遊戲。

## 遊玩方式

直接雙擊開啟 `index.html` 即可在瀏覽器遊玩。

## 操作

| 按鍵 | 功能 |
|------|------|
| 方向鍵 / WASD | 移動 |
| L | 觀察 |
| K | 攻擊 |
| I | 進入樓梯 / BOSS 房 |
| E | 使用回血道具 |
| H | 休息 |
| M | 地圖說明 |
| Q | 離開 |

也可用畫面上的按鈕操作。

## 檔案結構

- `index.html` — 主頁面
- `css/style.css` — 介面樣式
- `js/game.js` — 遊戲邏輯（移植自 game.c）
- `js/main.js` — 介面與輸入處理
